# midden-lab

> *A midden is an old dump for domestic waste.*

This is that, but digital. A personal lab where half-finished ideas, homelab infrastructure, and the occasional thing that actually works all get buried in the same pile — some of it composts into something useful.

## Dug up and cleaned off (public)

- **[nix-workspace-framework](https://github.com/midden-lab/nix-workspace-framework)** — I do a fair amount of work that hops between projects and teams; I created this to make space for isolated workspaces with specific binaries, aliases, env vars, scripts, etc. A bias toward NixOS and a desire not to use Mise - A declarative, per-project dev environment using Nix flakes, direnv, and zsh.
- **[ear-candy](https://github.com/midden-lab/ear-candy)** — A self-hostable podcast webapp for a single show: seasons and episodes with cover art, a built-in admin panel for managing all of it, and no third-party hosting in the loop. Fastify + SQLite on the server, React + Vite on the client.

## Still buried

A few other things fermenting in private repos — `hermes`, `out-rag`, `midden-cluster`. They'll surface here if and when they're ready for daylight.
